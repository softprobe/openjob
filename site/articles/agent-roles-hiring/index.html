AI-agent roles are hiring at Cloudflare, Stripe, Scale AI and Reddit — and your agent can read them all

OpenJob · November 21, 2026

Board

The companies building AI agents are hiring people to build AI agents — and every one of those roles is in an index your agent can already read. We matched all 5,107 job titles in our sample of the OpenJob index against a keyword set for agent work. Seventy-six matched. Forty-two of them were posted in the last 60 days. Here they are, at the companies you would hope.

Your agent can find them for you

This is the part a normal job board cannot do. Every role above lives in a public, agent-readable index: a manifest plus checksummed shards, an llms.txt that tells an agent how to read the board, and an MCP server so Claude, Cursor, and Codex can search it with a tool call instead of a browser. No account. No tracking. Paste this into the agent you already use:

"Read https://openjob.softprobe.ai/llms.txt and follow it. Find me a job building AI agents."

Then say the word on what you want — a company, a location, remote-only — and let it search. The board is at openjob.softprobe.ai; the source is github.com/softprobe/openjob. If you hire, post the role as a pull request — one Markdown file, validated and auto-merged — and your role shows up in the same index the next time someone's agent goes looking.

How we counted

  • Source: the public manifest at https://openjob.softprobe.ai/api/data/manifest.json, generated 2026-11-18T20:08:03Z; 33,107 jobs, 34 shards, complete: true.
  • Sample: 5,107 rows from shards 0, 7, 14, 20, 27, 33. The shards are source-blocked, not random — each shard holds exactly one ATS system — so this is a cluster sample. The sample has no Lever rows (Lever is 6.0% of the full dataset) and overweights Ashby. Percentages are sample percentages.
  • Method: word-boundary keyword match on the job title: agent, agents, agentic, llm, llms, genai, generative ai, prompt engineer, copilot, ai agent. Titles were not hand-classified; anything the keywords miss is missed, and anything they catch is counted. The fresh subset is roles posted in the last 60 days.
  • Indexed ≠ recruited. Every number describes rows indexed from employer ATS boards. OpenJob did not recruit these employers; the employers own the text.
