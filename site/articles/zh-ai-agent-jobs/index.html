AI Agent 岗位只占索引的 1.5%——但阶跃星辰、微博、大疆都在招

OpenJob · 2026年11月20日

招聘板

说明：我是 OpenJob 的维护者。这篇文章是我们对自己索引的公开审计。

人人都在招 AI Agent 的人。真数一数，几乎没有人招。我们读完了抽查中全部 5,107 个岗位标题，逐一对照 Agent 相关关键词匹配：76 个标题命中，只占索引的 1.5%。

这个小数字是诚实的数字——也是有意思的数字，因为这 76 个岗位正好集中在大家关心的公司，既有英文的，也有中文的。中国的 Agent 社区尤其应该看到这一半：阶跃星辰、微博、大疆都在用中文招 Agent 岗位。

什么算 Agent 岗位

我们只按岗位标题匹配（抽查中标题与职位字段 100% 一致），按词边界匹配，用了两组关键词：

  • 窄口径“AI Agent”：agent、agents、agentic、llm、llms、genai、generative ai、prompt engineer、copilot、ai agent。
  • 宽口径“AI/ML”：窄口径再加上 ai、artificial intelligence、machine learning、ml、deep learning、nlp、natural language、computer vision、data scientist、data science、generative。
岗位数占比
AI Agent 岗位（窄口径）761.5%
AI Agent 岗位（窄口径，新鲜子集）2,245 条中有 42 条1.9%
AI/ML 岗位（宽口径）3416.7%
AI/ML 岗位（宽口径，新鲜子集）2,245 条中有 169 条7.5%

新鲜子集——最近 60 天内发布的岗位——在两个口径上都略高一些（窄口径 1.9%，宽口径 7.5%）。这只是增长的迹象，不是证据：要谈趋势需要第二份快照，我们会每周重新统计一次。

按来源看，Greenhouse 的招聘板上 Agent 岗位最多（2,000 条中有 42 条，2.1%，来自 10 家雇主），其次是 Ashby（1,000 条中有 15 条，1.5%，5 家雇主），然后是 Moka（2,100 条中有 17 条，0.8%，5 家雇主）。

具体是哪些岗位

以下是抽查中真实的岗位标题——不是我们编的例子。中国的公司排在前面：

  • 阶跃星辰 (StepFun) — “Agent Harness 技术leader”；“Agent Infra-数据平台研发”；“AI Agent产品经理”
  • 新浪微博 (Weibo) — “AI Agent研发工程师”
  • 大疆 (DJI) — “中/高级多媒体算法工程师（AI/AIGC/AI Agent）”
  • Cloudflare — “Engineering Manager, Agentic Commerce”；“Senior Software Engineer, Agentic Discovery”
  • Scale AI — “Frontier Agents Engineer”；“Staff Product Manager, Agentic Platform”；“Senior Frontier Agents Engineer (Applied AI)”
  • Stripe — “Business Development Manager, Agentic Commerce”；“Staff Product Manager, ML Foundations and GenAI”
  • Reddit — “Senior Software Engineer, Agentic Ads Experience”
  • Hugging Face — “Senior Machine Learning Engineer, Voice Agents”
  • Robinhood — “Staff Machine Learning Engineer, AI Platform & Agentic Apps”
  • Softprobe — “Software Engineer — AI Agent QA & Observability”（抽查中唯一的 OpenJob 原生岗位）

“Agentic Commerce”同时出现在 Cloudflare 和 Stripe。“Frontier Agents”在 Scale AI 是一个岗位系列，不是一条招聘。而索引的中文一半同样有 Agent 岗位——阶跃星辰、微博和大疆都在用中文招人。

小，但真实

1.5% 小到足以纠正市场的 hype，又大到值得认真对待：76 个岗位，雇主个个有名，是一个真实存在的就业市场——而 OpenJob 这个招聘板正是为这个市场而建的。它的存在理由是：做 Agent 的人不会去刷招聘网站，他们会让自己已经在用的 AI 助手帮自己找工作。上面这些岗位，就是那个助手应该找到的岗位。

对中国的 Agent 开发者来说，这一点尤其直接：你不需要翻英文招聘板，阶跃星辰、微博、大疆的 Agent 岗位就在同一个索引里，用的是中文标题、同一套字段。让你的 AI 助手帮你找到下一份工作——中文也行。

我们是怎么数的

  • 来源：公开清单 https://openjob.softprobe.ai/api/data/manifest.json，生成于 2026-11-18T20:08:03Z；33,107 个岗位、34 个分片、complete: true。截至 2026 年 11 月 20 日，清单总数为 33,362 条；本篇的百分比来自 11 月 18 日的快照。
  • 抽查：5,107 条记录，来自编号 0、7、14、20、27、33 的分片。分片是按来源切分的，不是随机的——每个分片只装一个招聘系统（ATS）——所以这是一次整群抽查。抽查中没有 Lever 的记录（Lever 占完整数据集的 6.0%），Ashby 的比重被高估了。百分比都是抽查百分比。
  • 方法：按词边界对岗位标题做关键词匹配，用上面列出的两组关键词。标题没有经过人工分类；关键词漏掉的就漏掉了，命中的就计入。
  • 收录 ≠ 招募。所有数字描述的都是从雇主招聘板上收录的记录。OpenJob 没有招募这些雇主；文本归雇主所有。
