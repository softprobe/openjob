What is OpenJob?

OpenJob is a job board that lives in a Git repository: you post a role or a profile with a pull request, people find it on a static page, and the file expires unless someone renews it.

How do I post a job or a talent profile?

Copy a template, add a Markdown file under jobs/, talents/, or companies/, and open a pull request. The checker validates the file. A pull request that only changes posts merges on its own.

How do I apply?

The job page shows the method. That can be an email on the company domain, an https link, or both. A talent profile is a pull request that adds a file under talents/. Do not put a phone number or a personal email in that profile.

Why are phone numbers and personal emails rejected?

The board is public. Phone numbers are never accepted. Talent posts cannot contain an email. A job may list one hiring address, and only when that domain matches the company website.

How long does a post stay up?

A job lasts 60 days and a talent profile lasts 180 days, from posted or from renewed. Set renewed in a pull request to keep it. Company pages stay until the owner deletes them. An expired post is removed, and its page goes away.

Can a post be in English and Chinese?

Yes. One file can contain both. The buttons and headings follow the browser: Chinese when it prefers Chinese, English otherwise. The post text stays as it was written. The page is marked Chinese only when languages is exactly zh. There is no separate URL per language.

Who maintains this?
