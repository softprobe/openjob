## 标题

不想把电话交给招聘 App，我把职位发在了 GitHub 上

## 正文

最近不想再在招聘软件里留手机号，就做了一个完全公开的职位板，叫 OpenJob。

它就是一个 GitHub 仓库。想发职位，或者想放一份人才介绍，就提交一个 Pull Request，内容是一篇 Markdown。机器人会检查格式，并且拒绝电话号码和个人邮箱，就算写成「名字 [at] 邮箱」或用中文数字写手机号也会被拦下。

对方怎么联系你：留 LinkedIn、GitHub、个人网站，或者公司的投递链接。没有站内私信。

职位大概两个月过期，人才介绍大约半年，可以续。过期的帖子会从目录里拿走，需要的话还能从 Git 历史里找回来。中文和英文可以写在同一篇里。

仓库我放在评论里（或置顶）：https://github.com/zwobill/openjob

这不是中介，也没有人帮你内推。页面上如果还有标着示例的帖子，那是格式样例，不是在招人。
