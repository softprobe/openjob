## 标题

OpenJob：用 Pull Request 发布职位和人才档案

## 正文

做了一个放在 GitHub 仓库里的公开职位板，想替代「先把电话交给平台」这种发布方式。

发职位、人才档案或公司页，就是往仓库里加一篇 Markdown，开 Pull Request。Actions 会检查路径、大小（10 KB 以内、纯文本）和隐私：不要电话，不要个人邮箱，`[at]` / `[dot]`、全角字符、国内手机号这种写法也会被拒绝。Pull Request 只改这一篇且检查通过时，会 squash 合并。

职位默认挂 60 天，人才档案 180 天，可以续期。过期的文件从目录删除，Git 历史留着，需要时再恢复。完整档案也可以放在你自己的 `openjob-profile` 仓库，这里只留一条索引。

搜索是静态页面，可以按职位、地点、远程、语言和标签过滤。中英混写都可以。

没有站内信，也没有推荐算法。联系方式只能是 LinkedIn、GitHub、个人网站或公司申请链接。

仓库：https://github.com/zwobill/openjob
页面（需要先打开 GitHub Pages）：https://zwobill.github.io/openjob/

我是维护者。现在仓库里的示例帖是格式样例，不是真实招聘。欢迎提检查规则上的问题，不要把简历直接贴过来。
