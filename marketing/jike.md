# 即刻

Draft. Do not post.

发在和产品、独立开发相关的圈子里，用个人口吻。不要配联系方式卡片，不要写「私信我发 JD」。配图如果要加，就截一张搜索页，不要截别人的简历。

---

把职位板做成了一个 GitHub 仓库，叫 OpenJob。

发职位或人才档案 = 提一个 Pull Request。文件是带 front matter 的 Markdown。CI 会拒掉电话和个人邮箱，包括「名字 [at] 域名」和手机号的各种写法。联系方式只留链接：LinkedIn、GitHub、个人站，或公司的申请页。

职位 60 天、档案 180 天，过期就从目录里删掉，历史还在 git 里。不想把全文放在别人的仓库，也可以把档案放在自己的 `openjob-profile`，这里只留索引。

没有推荐，没有站内信。中文英文都能写。
