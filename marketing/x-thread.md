## English

1. I built OpenJob, a job board that is a GitHub repository. You post a job or a talent profile by opening a pull request. There is no account and no inbox.

2. The rule I cared about: no phone numbers and no personal email. Contact is a LinkedIn URL, a GitHub profile, a personal site, or the company's apply link. CI rejects the usual disguises, including "name [at] domain" and Chinese mobile numbers.

3. A job lasts 60 days, a profile 180, unless the author renews it. Expired files are deleted from the tree. Git history is the archive. The board does not accumulate dead posts.

4. You can keep the full profile in your own repo (`yourname/openjob-profile`) and put a short index entry in OpenJob. The listing is public. The canonical copy can stay yours.

5. Search is a static page. Filter by role, location, remote, language, and tags. English and Chinese in the same file is fine.

6. It is not a social network and it does not match people. It is a classifieds file with a schema and a merge bot.

7. Repo: https://github.com/zwobill/openjob
   Site (after Pages is on): https://zwobill.github.io/openjob/

8. If you post, one pull request, one file, your own GitHub login on the post. The checker squash-merges it when the file is valid.
