Redis built the product that runs the fast apps the world runs on, serving more than 10,000 customers worldwide. The team builds the surfaces developers touch every day: the Redis Cloud console, Redis Insight, and the agentic layer of MCP servers, CLIs, and agent skills that let an AI agent create, configure, and work with Redis end to end.

Redis works AI-native: agents write essentially all of the team's code and act as first responders on GitHub issues, alerts, and failing tests. The company is headquartered in San Francisco, California.
