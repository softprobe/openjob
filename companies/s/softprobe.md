Softprobe is the team behind AREX (https://github.com/arextest), an open-source automated record/replay regression testing platform.

The company builds two products. The first is automated record/replay–based Java regression testing at scale. The second is AI agent observability: performance reviews for AI agents, so a team can see where an agent underperforms, understand why, and prove the next version is better.

The agent product captures sessions. A team can review every step, including the exact input, output, timing, and failures. Agent Diagnosis is coming soon. It names the performance problem with evidence and a concrete next step. Softprobe is available with OpenCode. Earlier work at the company is API testing and observability built on full-fidelity session capture.

There is a free forever tier with unlimited session ingestion, and Teams and Enterprise plans.

Founded in 2025. Headquarters are in Los Altos, California, USA. The company has 1-10 employees, and the team is distributed across the United States and China (Shanghai). Founder and CEO is Bill Zuo, GitHub login zwobill.
