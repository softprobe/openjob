Redis is hiring a Senior Full-stack Engineer to shape how engineers, and the AI agents working alongside them, use Redis. The team builds the surfaces developers touch every day: the Redis Cloud console, Redis Insight, and the agentic layer of MCP servers, CLIs, and agent skills that let an AI agent create, configure, and work with Redis end to end.

You will lead initiatives end to end, from discovery and prototyping through design, implementation, testing, release, and monitoring; build and evolve the Redis console and its shared platform; build agentic interfaces to Redis so that anything a user can do in the UI, an agent can do too; and make agent-driven development reliable through quality gates, CI, eval harnesses, and review practices.

The role asks for 6+ years of experience building and shipping production software, ownership of the full SDLC, a product mindset, and daily hands-on use of AI coding agents (Claude Code, Cursor, Codex, or similar). Most of the work is TypeScript, with Rust CLIs, Python MCP servers, and Go prototypes. AI-native is how the team already works: agents write essentially all of its code. The role is based in Bulgaria with hybrid working options, and was published October 22, 2026. No salary is stated in the posting.
