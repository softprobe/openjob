Pydantic is hiring an Agent Infrastructure Engineer to build the infrastructure to run AI agents at scale — safely, reliably, and cheaply. Much of this is greenfield: a platform that can run untrusted, long-lived, resource-hungry agent workloads, for Pydantic's own agents first and ultimately for its customers.

The role designs and hardens the sandboxing model for running agent and customer code — container and microVM isolation, kernel sandboxes, network egress policy, and least-privilege credential minting — scales the agent runner with per-run isolation and fast cold-starts, and builds durable, resumable agent execution so runs survive pod failures. It also owns the orchestration path end to end and integrates the agent runtime with Pydantic's own observability in Logfire.

The role asks for experience building and operating cloud infrastructure for running agents or untrusted code at scale, strong skills with containers and Kubernetes and the security boundaries around them, solid Python, and at least 5 years of software engineering experience. It is fully remote, for someone living and working in a timezone between PT (UTC-8) and CET (UTC+1).
