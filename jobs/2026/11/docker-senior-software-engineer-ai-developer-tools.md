Docker is hiring a Senior Software Engineer for its AI Developer Tools team, building AI-powered developer tools and the platform behind them. You will work at the intersection of AI, developer experience, and platform engineering, building tools that make Docker's engineers more productive and the platform that lets teams across Docker prototype, deploy, and scale their own AI developer tools.

As a Senior Engineer you will design, build, and operate production AI agents for developer productivity — including code review assistants, test generators, deployment diagnostics, and incident response automation — integrate LLM providers, agent orchestration frameworks, and MCP servers into reliable tools, and build the self-service platform capabilities (deployment pipelines, observability, security controls, cost management) that help teams ship their own AI tools faster.

The role asks for 6+ years of software engineering experience building and operating production systems; hands-on experience building LLM-powered applications, AI agents, or AI-assisted developer tools; and experience building scalable backend services, distributed systems, or developer-facing platforms. Proficiency in Go (preferred), Rust, Java, or Python. The role is remote-first. The US base range is $160,900–$260,700, and all full-time roles include equity. The role was published October 14, 2026.
