Baseten is hiring a Software Engineer - Cloud Platform to join Cloud Platform Engineering and own the Kubernetes fleet that runs its production AI workloads. The role turns manual cluster operations into reliable, repeatable systems — from bringing new cloud providers online to rolling out configuration and upgrades safely across the entire fleet.

This is a hands-on software engineering role with ownership from design through production. The work includes building APIs, controllers, and automation that make infrastructure easier to operate, reduce configuration drift, and bring GPU capacity online, plus developing reusable Terraform modules and GitOps configuration that work across cloud and GPU infrastructure providers.

The role asks for experience building and owning production infrastructure software or distributed systems, strong programming skills in Go or another systems or backend language, deep experience with Kubernetes infrastructure including controllers or operators, and practical experience with infrastructure as code and GitOps tools such as Terraform and Flux or Argo CD. It is based in San Francisco, with remote as a secondary location.
