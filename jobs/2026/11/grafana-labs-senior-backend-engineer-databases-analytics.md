Grafana Labs is hiring a Senior Backend Engineer - Databases - Analytics for a new skunkworks initiative with a mission to bring observability to the rest of the business: an AI-native data intelligence system that gives agents reliable, governed access to enterprise context, so agents retrieve the right data, metadata, definitions, lineage, and quality signals without every agent builder maintaining brittle context files.

As a Senior Software (Database) Engineer, you will help build the underlying storage system for a general-purpose data platform, with both OLAP and OTLP capabilities to support classic analytics queries while serving freshly stored data. The work covers ingestion, query planning, distributed query execution, data formats, and storage formats, plus the architecture for a multi-tenant database service — tenant isolation, usage tracking, quotas, audit logs, and reliable service boundaries. You will also build APIs and database interfaces that let AI agents, MCP tools, CLIs, and internal applications retrieve data quickly.

The role asks for experience with distributed systems, catalogs and table formats, and query engines; mastery of a language like Go, C++, or Rust; and exposure to cloud-native environments. Bonus points for experience building distributed query engines, data warehouses or data lakes, and tools for data engineering. The role is remote, for applicants located in the US or Canada. The US base compensation range is $154,445–$185,334, plus RSUs. The role was first published September 28, 2026.
