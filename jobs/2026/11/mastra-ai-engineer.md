Mastra is hiring an AI Engineer to work on features that help developers understand their agents' behavior, evaluate their performance, and improve them over time. The role is hands-on engineering, moving between experiments, benchmarks, and product code, taking what is learned from evaluating agents and using it to shape the framework.

The work includes building trace intelligence and Agent Learning features that automatically self-improve agents, running Mastra primitives like memory on industry-standard benchmarks, and using the results to fine-tune configuration. It is fully remote.

The role asks for someone who has shipped agents and agentic applications into production, tuned them to improve accuracy, and can benchmark results against existing datasets or create them intelligently.
