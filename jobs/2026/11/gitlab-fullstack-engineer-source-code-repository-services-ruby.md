GitLab is hiring a Fullstack Engineer for its Repository Services team in the Create stage. The team owns the repository side of Source Code: how code gets into a repository, who may change it, and how those changes are verified — built as an access layer on the primitives the Gitaly team provides, for GitLab's own features and for the AI agents now writing and pushing code alongside people.

You will develop secure, well-tested, performant features using Ruby and GraphQL across GitLab.com, self-managed instances, and GitLab Dedicated; design and maintain backend services, APIs, data models, and business logic that control how code reaches a repository; and spend real time on performance and SQL tuning, caching, rate limiting, testing, observability, and resiliency. The team also expects you to use AI agents for well-scoped work when they can speed up delivery, and to critically review their output.

The role asks for professional experience building backend web applications, services, or APIs with Ruby and GraphQL; an understanding of relational databases, data modeling, caching, background processing, and backend performance; and experience with AI coding agents or an interest in building those skills in a complex monorepo. All GitLab roles are remote. The US base salary range is $115,200–$194,400. The role was first published October 29, 2026.
