Softprobe is hiring a software engineer. Softprobe is the team behind AREX (https://github.com/arextest), an open-source automated record/replay regression testing platform. The public site is https://www.softprobe.ai.

The company builds two products. The first is automated record/replay–based Java regression testing at scale. The second is AI agent observability: performance reviews for AI agents, so a team can see where an agent underperforms, understand why, and prove the next version is better.

What you'll build: the AREX record/replay engine and the Java agent, and the agent observability product. The work uses Java, JVM bytecode instrumentation, and distributed systems, and also TypeScript, Python, and LLM tooling.

What we look for: an engineer who will work on those systems with the team.

Why join: the record/replay platform is open source, so the work is public in AREX. The team is in Los Altos and Shanghai.

The role is based in Los Altos, California or Shanghai. Remote work is fine.
